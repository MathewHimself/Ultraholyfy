Этот проект был разработан с использованием двух нейросетей на разных этапах —
каждая применялась там, где её сильные стороны наиболее востребованы.


ИСПОЛЬЗУЕМЫЕ НЕЙРОННЫЕ СЕТИ
-----------------------------

  Claude (Anthropic)  —  Архитектура, декомпозиция задачи, первичный код
  DeepSeek            —  Доработка, отладка, оптимизация деталей


ПАЙПЛАЙН РАЗРАБОТКИ
---------------------

Этап 1 — Проектирование архитектуры в Claude
..............................................

Первоначальная задумка проектировалась в Claude с конкретным описанием
структуры кода:

  - явно задавались классы и функции с их зонами ответственности
  - описывалось как они должны взаимодействовать между собой
  - Claude генерировал скелет кода, придерживаясь заданных интерфейсов

Такой подход позволил получить чистую, логически связную архитектуру без
«размытых» решений — Claude хорошо держит контекст требований и генерирует
структурированный код при детальном промпте.

Этап 2 — Доработка в DeepSeek
..............................

После получения рабочего прототипа из Claude проект передавался в DeepSeek
для итеративной доработки:

  - исправление мелких багов и edge cases
  - оптимизация параметров 
  - адаптация кода под конкретный контейнер вместо window

DeepSeek хорошо справляется с точечными правками и объяснением поведения
уже существующего кода.
